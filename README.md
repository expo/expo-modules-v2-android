# Expo Modules API v2 Android

Modules can be written in Kotlin, with the annotations of this project, or in C++, with
[the C++ API](api/src/main/cpp/expo-modules-cpp/README.md). They share one `expo.modules`, and the
C++ API has the same features: functions, properties, constants, events, shared objects, records,
enums, promises and typed arrays — without a JNI call between JavaScript and your code.
